# Retired registry pilot

Install the [GitHub Release archive](../README.md#install-the-library). Registry hosting was retired after deployments failed to update the served content.

The registry workflow no longer deploys. Keep the local source and `pnpm registry:check` for provenance and token consistency.

The [historical pilot design](history/registry-pilot-2026-09-10.md) records the original setup. Its hosted URLs are not supported installation routes.
