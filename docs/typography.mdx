# Typography in use

Roobert is the primary family, followed by Geist and system sans. The specimens below read their size, leading and weight values from the same generated token data as the components. Values in rem respect the reader's browser settings.

Use one display heading per page, section headings for groups and compact labels for controls. Keep supporting copy readable. Reserve captions for brief secondary details, and use tabular numerals for data comparisons.
